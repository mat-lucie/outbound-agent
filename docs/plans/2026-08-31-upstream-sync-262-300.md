## Method (same as the 2026-07-20 sync)

- Themed branches, stacked in order (each based on the previous), one PR each,
  squash-merged bottom-up once `quality-gates` CI is green.
- Port the upstream diff, then apply the standing adaptation seams:
  - `LUCIE_*` env → `OUTBOUND_*` (with `LUCIE_*` back-compat alias), `~/.lucie-sales` → `~/.outbound-agent`
  - CRM access via `CRMProvider` or the sanctioned `_attio_inner_client(crm)` escape hatch (tracked in CONTRACT.md)
  - new thresholds/IDs → `clients/outreach_config.py` / `clients/pb_config.py` / `config/icp.example.yaml` knobs, mirrored in `examples/acme/config/`
  - operator copy/keywords → neutral placeholder in `content/` + synthetic acme values in `examples/acme/`
  - NO real prospect/company/person names, no live IDs: `scripts/check_no_secrets.py` (incl. `NAMES_DENYLIST`) must stay green
- Gates per branch: `ruff check`, `mypy` (no NEW errors), secrets gate, `python -m pytest -q` (no fail).
- Behavioral branches get an adversarial review (port-fidelity + silent-failure lenses) before PR.
- Final whole-stack review over `main...<top branch>` before declaring done.
